Sobre o Linux

Linux é um sistema operacional de código aberto, criado por Linus Torvalds em 1991. Ele é utilizado em computadores, servidores e diversos outros dispositivos.

Objetivo do site

Este site foi criado para apresentar informações básicas sobre o Linux, suas distribuições e seus principais comandos.

Comunidade

O Linux possui uma grande comunidade de usuários e desenvolvedores que colaboram para melhorar o sistema.
